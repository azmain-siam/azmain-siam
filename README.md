### 🚀 About Me

I am a **Full-Stack Developer** passionate about architecting scalable backend systems, designing clean APIs, and crafting intuitive, modern frontend experiences.

- 🔭 **Currently Building**: Real-time collaborative workspace platforms with **NestJS**, **Redis**, **BullMQ**, **Socket.IO**, and **Next.js**.
- ⚙️ **Backend Specialty**: Clean architecture, asynchronous background jobs, caching strategies, and relational data modeling with **PostgreSQL & Prisma ORM**.
- 🎨 **Frontend Craft**: Modern UI systems with **React 19**, **Next.js (App Router)**, **Tailwind CSS**, and **Zustand**.
- 🎯 **Career Goal**: Contributing to high-impact engineering teams, solving real-world business challenges, and scaling distributed architectures.
